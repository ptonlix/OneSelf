Every AI

每个 AI 都能自助接入

装上 Skill 的 Agent 就会用。HTTP 和 MCP 是同一套操作，读到的永远是最新的你。

效率

一份上下文，所有 AI 共用

  • 不用每次重新介绍自己，Agent 帮你整理、补充资料
  • 按关键词、条件或事实检索，记住或忘掉一条事实
  • 改动留有版本，删除后 30 天内可恢复
隐私

默认私有，边界由你划定

  • 按目录授权读、写、改可见性；没授权的内容，Agent 看不到
  • 每把 Key、每条授权都能单独收回，立即生效
  • 资料和原件都存在你自己的机器上
安装 Skill

一条命令
你的 Agent 就认识你了

之后只要说一句话：资料它来整理，展示页它来做。

$npx skills add https://<你的站点>

<你的站点> 换成这个页面所在的地址。

每页默认私有。设为 public 后，这一页和它的原件任何 AI 都能匿名读取；改回 private 立即不可见。

谁能读到
public任何 AI 和你的展示页，不需要凭据
private只有你授权的 Agent

公开资料改了，展示页下次打开就是新的，不用重新上线。
