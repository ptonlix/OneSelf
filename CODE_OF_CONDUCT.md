# 行为准则 / Code of conduct

参与 Issue、Pull Request、Discussions 和这个仓库里的其他公开空间时，遵守下面几条。

These rules apply to issues, pull requests, discussions, and the other public spaces of this repository.

## 请这样相处 / How to take part

- 对事不对人。可以不同意一个设计，不要攻击写它的人。
- 批评带上你看到的文件、命令或错误码，方便别人核对。
- 接受维护者按 `docs/PRD.md` 把一项提议标成这一版不做。
- 别人的 OneSelf 实例不是公共资料。没有本人同意，不要张贴他的页面、原件、导出包或截图。

Disagree with the work, not the person. Point at a file, a command, or an error code. A maintainer may mark a proposal as out of scope for this version because `docs/PRD.md` says so. Someone else's OneSelf instance is not public material. Do not post their pages, originals, export archives, or screenshots unless they agreed.

## 请不要 / Do not

- 贴所属人密码、API Key 原文、OAuth 令牌、对象存储密钥，或带口令的连接串。
- 骚扰、歧视，或公开别人的私人信息。
- 把这个仓库里的讨论搬去人肉搜索。

Do not post owner passwords, API key secrets, OAuth tokens, object-storage secrets, or connection strings that contain a password. Do not harass, discriminate, or publish someone's private information. Do not use a discussion here as a starting point for doxxing.

## 维护者可以做什么 / What maintainers may do

仓库所有者可以编辑、隐藏或关闭不符合这页的 Issue、评论和讨论，也可以拒绝相应的 Pull Request。

The repository owner may edit, hide, or close an issue, comment, or discussion that breaks this page, and may reject the corresponding pull request.

## 怎么报告 / How to report

不含私人数据的一般情况，写给仓库所有者。

如果报告本身含有别人的个人上下文、密钥，或是一个漏洞，走 [SECURITY.md](SECURITY.md) 里的私人渠道，不要开公开 Issue。这个仓库没有单独的行为准则邮箱。

For an ordinary report that contains no private data, write to the repository owner. If the report includes someone else's personal context, a secret, or a vulnerability, use the private path in [SECURITY.md](SECURITY.md) and do not open a public issue. This repository does not have a separate code-of-conduct email.
