# Proposal

## Why

页一多，星图正面会把每页标题叠成一块读不了的牌子。标题是不换行的胶囊，投影又不避让；目录中心还固定在半径 120 的环上，大目录会吞掉旁边的目录。所属人需要在默认镜头下认出目录和一部分页，其余标题指到星上再出现。

## What Changes

- 每页仍是一颗星。标题只在不盖住其它目录名、幽灵标签或页标题时画出来。指到这颗星上，或选中这一页时，标题必须出现，即使会盖住别人。
- 目录名和断链幽灵的 `source/slug` 始终显示。选中一个目录时，优先留下这个目录里放得下的页标题。
- 无法绘制星图时的页名列表仍列出全部标题。
- 目录按页云大小分开，单目录放在原点。页铺在朝向初始镜头的球冠上，不再铺满整个球。放不下时把初始镜头拉远，缩放条的最左端跟着变远。
- 连线仍是点线，端点仍落在两颗星上。没有选中页时连线变淡；选中一页后，碰到它的连线更亮，其余更淡。

## Capabilities

### New Capabilities

- 无。

### Modified Capabilities

- `admin-nebula`: 标题在拥挤时退让，指到星上再出现；目录分开；连线随选中变亮变淡。

## Impact

- `apps/admin` 的星图布局、标签投影和连线透明度。不改 `GET /admin/graph`，不新增操作，不进 MCP。
