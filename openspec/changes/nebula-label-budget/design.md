# Design

## 为什么这样

屏幕上的标题宽度和三维间距不是一回事。球的正面会把前后分开的星投到同一片圆盘上，所以只把云放大不能让标题分开，还会把目录推出镜头。标题要在投影之后按矩形避让。星星本身仍然都在，点选和侧栏列表不受影响。

## 布局

- 页云半径按页数的平方根增长，让邻近星大约保持可点选的间距。线性半径会让大目录超出缩放范围，却仍然解决不了标题重叠。
- 多个目录放在压扁的环上。环的半径至少是 120，并且放大到相邻页云之间留出空隙。只有一个目录时放在原点，避免整团云偏到一边。
- 页放在朝向 +Z 的球冠上，纵深只留一截，把间距留给画面上的横纵方向。世界转动之后球冠不再正对镜头，避让仍每帧重算。
- 光晕、目录名和点击范围都跟着星团走，不用 `24 + 页数 × 5`。那个线性半径会把目录名甩出云外，并让大目录的点击球盖住旁边的星团。目录之间按光晕半径再加空隙分开。点到页星时选页，不选盖在上面的目录。
- 初始距离仍是 268，除非包围盒在这个距离下放不下。放不下时拉到能框住的距离，最远不超过 1600。缩放条 0 对应该次的最远距离，1 仍是最近。

## 标签

- 投影后做贪心：目录名、幽灵标签、悬停的页、选中的页强制留下。其余按「选中目录优先，其次离镜头近」放入，矩形碰上已占用的就隐藏。
- 隐藏用 DOM `hidden`，不交给 React，避免缩放重绘把标题又藏起来。安静宽度缓存一次，因为 `hidden` 之后读不到尺寸。悬停时的全宽不写入这份缓存。
- 默认标题是带阴影的字，限宽省略。悬停和选中才用胶囊并显示全文。无 WebGL 的列表不限宽。

## 连线

- 不选中时透明度 0.24。选中一页后，碰到它的连线是 0.9，其它是 0.07。端点坐标不变，仍然是点，不是实线。

## 不做什么

- 不按月份聚类，不把星图改成网格。
- 不改图接口，不把原件画成星。
