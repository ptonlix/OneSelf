# Proposal

## Why

管理端首页现在是一排概览卡片，资料只在 `/admin/records` 里以目录名列表出现。所属人看不到一页和另一页的 `[[source/slug]]` 关系，也不知道一个目录里有哪些页。已经确认的交互是：打开管理端就是整屏星图，目录是星云，页是恒星并标出页名，按住拖动或触控板两指可以转满一圈；需要管理时再点开右下角操作框。

## What Changes

- **BREAKING** `/admin` 不再渲染现在的概览卡片（轨道图、密钥、站点、已批准设备、无凭据空状态）。首页是星图，放在现有侧栏的第一项。侧栏可以收起，收起后星图铺满视口。设备码、API Key、站点、密码和资料列表仍走现有路由，留在同一侧栏里。
- 星图只画未删除目录和其中未删除、未被目录隐藏的页。每团星云是一个目录，每颗恒星是一页，恒星旁始终显示页名。原件不是恒星。`[[source/slug]]` 用点状星光连接两端，端点落在对应恒星上。指向已不存在或已隐藏页的链接仍画出来，末端是暗星并标出 `source/slug`。
- 按住主键拖动可向任意方向转动，没有上下限位。触控板两指滑动同样转动；捏合才拉近。天空在无人操作时缓慢自转，速度与现在概览轨道的自动转速同一量级；人手一开始转动就停下，松开约一秒后再恢复。`prefers-reduced-motion: reduce` 时不自转，拖动仍可用。
- 点恒星或星云，右下角弹出操作框。目录可二次确认后调用已有的 `sources_delete`。页可二次确认后调用已有的 `delete_page`。框内列出标题、路径、可见性、指出和指回、原件类型，不含正文，也不能在这里改 Markdown。
- 新增仅所属人会话可用的 `GET /admin/graph`。不新增 PCP 操作，不进 MCP，不进 OpenAPI。响应不含 Markdown、凭据和原件字节。
- 无凭据时的设备码接入提示，以及「已批准设备」列表，从概览挪走后仍必须能到达：接入提示出现在星图上，不挡住转动；已批准设备列表改到 `/admin/device`。`/admin/records` 的目录删除、30 天恢复和最近写入保持不变。
- 管理端新增 `three` 依赖，只用于这块星图。不使用 TrackballControls。

不改 `docs/PRD.md`。不新增错误码、链接类型、向量索引或第二份操作表。

## Capabilities

### New Capabilities

- `admin-nebula`：所属人打开 `/admin` 时看到的整屏星图、它的读模型和右下角操作。

### Modified Capabilities

- 无。主规格目录 `openspec/specs/` 目前没有已归档能力。未归档的 `access` 要求概览读现有操作并展示卡片；本变更用星图替换 `/admin` 的那一块，并在设计里写明如何安置被移走的面板。不把未归档变更写成已生效规格。

## Impact

- `apps/admin`：首页换成星图；新增 `three`。其他管理路由保留现有壳。
- `apps/server/src/owner`：`GET /admin/graph`，只认所属人会话。
- `packages/operations`：不改。
- 未归档的 `owner-continuity` / `redesign-orbit-ui` 里「概览必须展示卡片」与本变更冲突。实现时以本变更的 `/admin` 行为为准，不删除那些变更里资料列表、恢复和最近写入的要求。
